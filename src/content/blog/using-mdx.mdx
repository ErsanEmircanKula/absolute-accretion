Bu tema [@astrojs/mdx](https://docs.astro.build/en/guides/integrations-guide/mdx/) entegrasyonu yüklü ve yapılandırılı halde gelir. MDX'i kullanmak istemiyorsanız, entegrasyonu config dosyasından kaldırarak devre dışı bırakabilirsiniz.

## Neden MDX?

MDX, JavaScript ve JSX sözdizimini destekleyen özel bir Markdown türüdür. Bu, [JavaScript ve UI bileşenlerini Markdown içeriğine karıştırabilmenizi](https://docs.astro.build/en/guides/integrations-guide/mdx/#mdx-in-astro) sağlar - etkileşimli grafikler veya uyarılar gibi şeyler için.

Eğer MDX'te yazılmış mevcut içeriğiniz varsa, bu entegrasyon Astro'ya geçişi kolaylaştıracaktır.

## Example

Here is how you import and use a UI component inside of MDX.  
When you open this page in the browser, you should see the clickable button below.

import HeaderLink from '../../components/HeaderLink.astro';

<HeaderLink href="#" onclick="alert('clicked!')">
	Embedded component in MDX
</HeaderLink>
